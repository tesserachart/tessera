# Generated protocol types

Written by `bun run gen` (the `tessera-gen` binary of `crates/tessera-runtime`): the ts-rs types the runtime's modules
export, plus `ToolMap.ts`, `TopicMap.ts`, `indicators.ts`, `chartTheme.ts` and `index.ts`. Do not edit them by hand;
`../index.ts` re-exports them, and `bun run gen:check` fails when they are stale.
